[b]Candle Pattern Library[/b]

A Pine Script™ v6 library for classifying single candles and detecting
two-candle and three-candle patterns. It returns typed analysis data that a
consumer can use for plots, alerts, tables, or strategy logic.

[b]Current Version[/b]

[b]v5[/b]

[pine]
import OneCleverGuy/CandlePatternLibrary/5 as CPL
[/pine]

[b]Quick Start[/b]

Create one shared configuration and pass it to every analysis call. Multi-candle
calls require chronological order: older candles first, newest candle last.

[pine]
import OneCleverGuy/CandlePatternLibrary/5 as CPL

float avgSize = ta.atr(14)

CPL.CandleAnalysisConfig config = CPL.CandleAnalysisConfig.new(
    50.0,  // sizeThresholdPct
    10.0,  // equivTolerance, in absolute price units
    50.0,  // bodyTolerance, in absolute price units
    85,    // positionThreshold
    10.0,  // fvgMinGap, in absolute price units
    2.0,   // atrMultiplier
    0.5    // wickWeight
)

CPL.CandleData newest = CPL.analyzeCandle(
    open, high, low, close, avgSize, config)

CPL.CandleData middle = CPL.analyzeCandle(
    open[1], high[1], low[1], close[1], avgSize, config)

CPL.CandleData oldest = CPL.analyzeCandle(
    open[2], high[2], low[2], close[2], avgSize, config)

CPL.TwoCandleData two = CPL.analyzeTwoCandlePattern(
    middle, newest, config)

CPL.ThreeCandleData three = CPL.analyzeThreeCandlePattern(
    oldest, middle, newest, config)

[score, shape, power, bodyRatio, wickBias] =
    CPL.scoreCandleSentiment(
        open, high, low, close, ta.atr(14), config)
[/pine]

[b]Configuration[/b]

[list]
[*][b]sizeThresholdPct[/b]: Percent above/below average size used for Long and Short classification.
[*][b]equivTolerance[/b]: Absolute price tolerance for direction, equality, Doji, Marubozu, and tweezer checks.
[*][b]bodyTolerance[/b]: Absolute price tolerance for small-body classification.
[*][b]positionThreshold[/b]: Body-placement threshold used by hammer, shooting-star, and tweezer checks.
[*][b]fvgMinGap[/b]: Minimum absolute price gap used for fair value gap detection.
[*][b]atrMultiplier[/b]: Range/ATR multiple required for full sentiment power.
[*][b]wickWeight[/b]: Wick contribution to sentiment shape.
[/list]

[b]Core Results[/b]

[list]
[*][b]CandleData[/b]: Candle range/body measurements plus size, direction, pattern, and source OHLC.
[*][b]TwoCandleData[/b]: Detected two-candle pattern plus the older and newer CandleData values.
[*][b]ThreeCandleData[/b]: Detected three-candle pattern plus the oldest, middle, and newest CandleData values.
[*][b]scoreCandleSentiment[/b]: Returns score, shape, power, body ratio, and wick bias.
[/list]

[b]Important Usage Rules[/b]

[list]
[*]Analyze each candle with analyzeCandle before passing it to a multi-candle analyzer.
[*]Reuse one configuration across all candles in the same sequence.
[*]Pass two-candle data as older, newer.
[*]Pass three-candle data as oldest, middle, newest.
[*]Tolerance and gap settings are absolute price units, not ticks.
[*]The library does not create chart objects, call alert(), or manage strategy state.
[/list]

[b]Release History[/b]

Keep future version updates in this section, below the current publication
description, with the newest version first.

[b]v5[/b]

Added the shared CandleAnalysisConfig UDT so the main analysis calls use one
reusable configuration object instead of separate positional settings.

[b]Changed[/b]

[list]
[*]Added CandleAnalysisConfig with sizeThresholdPct, equivTolerance, bodyTolerance, positionThreshold, fvgMinGap, atrMultiplier, and wickWeight.
[*]Updated analyzeCandle(...) to accept _avgSize and CandleAnalysisConfig.
[*]Updated analyzeTwoCandlePattern(...) to accept CandleAnalysisConfig.
[*]Updated analyzeThreeCandlePattern(...) to accept CandleAnalysisConfig.
[*]Updated scoreCandleSentiment(...) to accept CandleAnalysisConfig.
[*]Updated the exported fair value gap predicates to read fvgMinGap from CandleAnalysisConfig.
[/list]

[b]Migration[/b]

[list]
[*]Build one CandleAnalysisConfig in the host script.
[*]Reuse that config for single-candle, two-candle, three-candle, fair value gap, and sentiment calls.
[*]Replace pre-v5 positional threshold and sentiment arguments with the config object.
[/list]

[b]v6 Update[/b]

Version 6 adds reusable result-family classification and centralizes shared
pattern-family knowledge inside CandlePatternLibrary. This update is appended
because previously published TradingView release text cannot be edited.

[b]Version 6 Import[/b]

[pine]
import OneCleverGuy/CandlePatternLibrary/6 as CPL
[/pine]

[b]Added[/b]

[list]
[*]Added isReversalSinglePattern(), isDojiPattern(), and isMarubozuPattern() for completed single-candle results.
[*]Added isEngulfingTwoPattern(), isTweezerTwoPattern(), and isRailRoadTwoPattern() for completed two-candle results.
[*]Added isStandaloneFairValueGapThreePattern() for pure BullishFairValueGap and BearishFairValueGap results. Combined soldier/crow plus FVG results remain distinct patterns.
[*]These helpers classify already-detected enum results; they do not rerun pattern detection or apply consumer-specific trading policy.
[/list]

[b]Improved[/b]

[list]
[*]Morning Star, Evening Star, and both Abandoned Baby predicates now use the same authoritative Doji-family classification.
[*]Repeated Normal-or-Long size checks now use one internal helper.
[*]Sentiment power returns 0.0 when atrMultiplier is na, zero, or negative instead of dividing by an invalid multiplier.
[*]The reference indicator now uses the shared CandleAnalysisConfig API and supplies avgSize[1] and avgSize[2] when analyzing historical candles.
[*]Candle Pattern indicator source files now use the .pine extension.
[/list]

[b]Migration[/b]

[list]
[*]Update imports to CandlePatternLibrary/6.
[*]Replace consumer-owned enum member lists with the new result-family helpers where appropriate.
[*]When analyzing historical candles, pass each candle the average-size series value from the same bar.
[*]Keep consumer-specific filters, such as requiring a Long engulfing candle or suppressing duplicate journal events, in the consumer.
[/list]
